# 🐾 Practo for Animals

### Discover trusted veterinary care and animal welfare services in one place.

Practo for Animals is a responsive web application prototype designed to help pet owners discover veterinary clinics, animal hospitals, pet boarding facilities, diagnostic services, animal ambulances, and animal welfare organizations.

The platform aims to simplify access to animal healthcare through an intuitive search experience, service discovery, and convenient provider information.

---

## ✨ Key Features

- **Service Discovery:** Explore veterinary clinics, hospitals, pet boarding, diagnostics, animal ambulances, and NGOs.
- **Smart Search:** Search for animal healthcare providers using location and keywords.
- **Advanced Filters:** Refine results by service category, minimum rating, location, and availability status.
- **Provider Information:** View provider details and available contact information.
- **Emergency Discovery:** Easily identify animal emergency care options.
- **List Your Business:** Allow veterinary service providers to submit their business information.
- **Submit a Correction:** Provide a way to report incorrect or outdated provider information.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Manu1067/practo-for-animals.git
   ```

2. Navigate to the project directory:

   ```bash
   cd practo-for-animals
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure environment variables if required.

   If the application uses Gemini API integration, create a `.env.local` file in the project root:

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   ```

   Never commit API keys or other secrets to GitHub.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal, usually:

   ```text
   http://localhost:5173
   ```
