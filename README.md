 
# 🐾 Practo for Animals

**One platform for every pet's healthcare needs.**

Practo for Animals is a pet-care discovery platform designed to help pet parents find veterinary clinics, animal hospitals, pet boarding facilities, diagnostic centres, animal ambulances and animal welfare organizations.

🔗 **Live Demo:** https://practo-for-animals-egtx.vercel.app/  
💻 **GitHub:** https://github.com/Manu1067/practo-for-animals

## ✨ Features

- **Service Discovery:** Explore six categories of animal healthcare services.
- **Smart Search:** Search for providers based on service and location.
- **Provider Listings:** View provider profiles, ratings, services, facilities and contact information.
- **Emergency Care:** Discover emergency hospitals and animal ambulance services.
- **Provider Details:** Explore consultation fees, doctors, opening hours and available facilities.
- **Responsive Design:** Optimized for desktop and mobile devices.
- **Community Contributions:** Designed to support provider information corrections and submissions.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Manu1067/practo-for-animals.git
cd practo-for-animals
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## 🎯 Product Objective

The goal is to simplify pet healthcare discovery by bringing multiple animal-care services together in one accessible platform.

## ⚠️ Note

This project is an MVP/prototype. Provider information and sample listings are illustrative and should not be treated as independently verified real-world business information.
